# Dony Invoice Desktop

Aplikasi desktop Tauri + SvelteKit untuk membuat penawaran, invoice, dan kwitansi dengan database SQLite lokal.

## Fitur

- Dashboard jumlah dan nominal dokumen
- Penawaran, invoice, dan kwitansi
- List klien lokal
- Pilih klien langsung dari form dokumen
- Rich text untuk catatan item
- Catatan default terpisah per jenis dokumen
- Warna dokumen terpisah untuk penawaran, invoice, dan kwitansi
- Preview A4
- Print A4
- Export PDF
- Riwayat dokumen
- Data perusahaan, rekening, logo, dan tanda tangan

## Menjalankan aplikasi

```bash
npm install
npm run tauri dev
```

## Cek frontend

```bash
npm run check
npm run build
```

## Build installer

```bash
npm run tauri build
```
